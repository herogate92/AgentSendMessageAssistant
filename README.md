# AI Agent 자동 프롬프트 입력기 (작업 큐 & 자동 타이핑 에디션)

AI Agent(Codex 등)의 토큰 소진 시, **사용자가 입력창에 미리 글을 써두지 않아도** 프로그램에 예약해 둔 프롬프트를 지정 시각에 **해당 창의 입력창을 마우스로 자동 클릭 ➜ 프롬프트 붙여넣기 ➜ Enter 전송**까지 100% 완전 자동으로 실행해 주는 프로그램입니다.

---

## 📌 주요 특징

- **입력 위치 자동 감지 (`[🎯 입력 위치 찍기]`)**:
  - 버튼을 누르고 3초 안에 대상 창(브라우저/샌드박스)의 텍스트 박스를 콕 클릭하면, **창의 식별자(HWND)와 입력창 상대 좌표(X, Y)를 동시에 자동 캡처**합니다.
  - 실행 시 창이 다른 곳으로 이동되어 있어도 상대 위치를 찾아 마우스를 이동해 클릭하므로 정확히 입력창이 활성화됩니다.
- **클립보드 + Ctrl+V 고속 무오류 타이핑**:
  - 한글 자모 분리나 긴 텍스트 입력 지연 없이, 순수 Win32 클립보드 복사 후 Ctrl+V로 0.1초 만에 깔끔하게 붙여넣습니다.
  - 여러 줄의 긴 코드 블록이나 긴 프롬프트도 원형 그대로 입력됩니다.
  - **Windows Sandbox(샌드박스)**에서도 호스트 클립보드 공유로 100% 동일하게 동작합니다.
- **작업 큐(Queue) 순차 실행**:
  - 새벽 2시, 4시, 7시 등 각 시간대마다 서로 다른 프롬프트와 서로 다른 창을 큐에 등록해둘 수 있습니다.
  - 시간순으로 차례대로 실행되며, 하나가 끝나면 자동으로 다음 작업으로 넘어갑니다.
- **비워둘 경우 기존 방식(Enter만 전송) 동작**:
  - 프롬프트 입력란을 비워두면 기존처럼 창 활성화 후 Enter만 전송할 수도 있습니다.
- **즉시 테스트 기능**:
  - `[⚡ 즉시 테스트 (3초 뒤 클릭+입력+엔터)]` 버튼으로 잘 동작하는지 바로 확인 가능!

---

## 🚀 사용 방법

1. `run.bat` 파일을 더블 클릭하여 실행합니다.
2. **대상 창 및 입력 위치 지정**:
   - **`[🎯 입력 위치 찍기 (3초 카운트다운)]`** 버튼을 누릅니다.
   - 비프음이 울리는 3초 동안 Codex 창(브라우저 또는 Windows Sandbox)의 **메시지 입력란**을 마우스로 콕 클릭합니다.
   - 대상 창과 클릭 좌표가 자동으로 등록됩니다.
3. **프롬프트 내용 및 시각 작성**:
   - "전송할 프롬프트 내용" 상자에 AI에게 보낼 지시사항을 입력합니다. (예: `기존 코드에 단위 테스트를 추가해줘.`)
   - 실행할 **컴퓨터 시각**을 설정합니다 (예: `02`시 `30`분).
4. **큐에 추가 및 추가 작업 등록**:
   - **`[➕ 위 설정을 작업 큐에 추가하기]`** 버튼을 누릅니다.
   - 2번째, 3번째 작업도 필요하면 다른 프롬프트와 시각으로 계속 추가할 수 있습니다.
5. **예약 실행**:
   - **`[▶ 큐 순차 실행 시작]`** 버튼을 누르고 편하게 주무시거나 다른 작업을 하시면 됩니다!
