# AI & 메신저 자동 메시지/프롬프트 전송기 (반복 & 편집 에디션)

AI Agent(Codex 등) 및 메신저(카카오톡, 디스코드, 슬랙, 텔레그램 등)의 반복적인 메시지/프롬프트 전송을 위해, **1) 작업 큐 더블클릭 편집/수정 기능**과 **2) 분/시간 단위 자동 반복 전송(무한/기간지정/횟수지정) 기능**을 탑재한 자동화 프로그램입니다.

---

## 📌 주요 특징

- **작업 큐 더블클릭 간편 수정 (`[✏️ 선택 작업 수정]`)**:
  - 등록된 작업의 시간, 메시지 내용, 대상 창, 반복 주기를 바꾸고 싶을 때, 목록에서 **더블클릭**만 하면 상단 입력창으로 그대로 불러와집니다.
  - 내용을 수정한 뒤 `[💾 수정 내용 저장하기]`를 누르면 큐 목록에 즉시 업데이트됩니다.
- **분/시간 단위 주기적 반복 실행 (Recurring Tasks)**:
  - **반복 주기**: 매 N분마다 또는 매 N시간마다 자동 재전송
  - **종료 조건 선택 (3가지)**:
    1. **무한 반복 (기본)**: 사용자가 큐 중지 버튼을 누를 때까지 영구 반복
    2. **종료 시각 지정**: 지정한 시각(예: 오늘 18:00:00)까지만 반복하고 자동 종료
    3. **횟수 제한**: 총 N회(예: 10회) 실행 후 자동 종료
  - 1회 실행 후 작업이 끝나는 것이 아니라, 다음 회차 시각으로 자동 재스케줄링되어 큐에 유지됩니다.
- **입력 위치 자동 감지 (`[🎯 입력 위치 찍기]`)**:
  - 버튼을 누르고 3초 안에 대상 창의 텍스트 박스를 클릭하면 창 식별자(HWND)와 상대 좌표(X, Y)를 동시 기억
  - 창이 이동되어 있어도 상대 위치를 찾아 마우스로 자동 클릭
- **64비트 호환 Win32 클립보드 + Ctrl+V 고속 무오류 입력**:
  - 한글 자모 분리나 지연 없이, 순수 Win32 클립보드로 0.1초 만에 붙여넣기
  - Windows Sandbox(샌드박스)에서도 호스트 클립보드 공유로 100% 동일하게 동작
- **컴퓨터 시스템 시각 기준 정렬**:
  - 모든 큐 작업은 컴퓨터 시간 순서대로 자동 정렬되어 순차적으로 정확하게 실행됩니다.

---

## 🚀 사용 방법

1. `run.bat` 파일을 더블 클릭하여 실행합니다.
2. **대상 창 및 입력 영역 지정**:
   - **`[🎯 입력 위치 찍기 (3초 카운트다운)]`**를 누르고 3초 안에 메신저나 AI 입력창을 마우스로 한 번 클릭합니다.
3. **메시지 및 시작 시각 작성**:
   - 보낼 메시지/프롬프트를 입력하고, 컴퓨터 기준 시작 시각을 설정합니다.
4. **반복 옵션 설정 (선택 사항)**:
   - `[V] 이 작업을 주기적으로 반복 실행하기` 체크
   - 매 `30` `분`마다, `무한 반복` 또는 `종료 시각` / `총 N회` 선택
5. **큐에 추가 및 실행**:
   - **`[➕ 위 설정을 작업 큐에 추가하기]`** 클릭
   - **`[▶ 큐 순차 실행 시작]`**을 누르면 정해진 시각 및 주기에 맞춰 전자동으로 발송됩니다!
6. **작업 수정 방법**:
   - 큐 목록에서 수정하고 싶은 줄을 **마우스로 더블클릭** ➜ 내용 수정 ➜ **`[💾 수정 내용 저장하기]`** 클릭!
